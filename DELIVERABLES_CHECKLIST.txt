HOW TO RUN (FOR GRADER)
===============================================================================

1. Install R packages once:
   install.packages(c("haven", "dplyr", "fixest", "tibble", "purrr", "flextable"))

2. Set working directory to project root:
   setwd("path/to/R_seminar")

3. Run master script:
   source("scripts/run_all_tables_with_log.r")

4. Review outputs in output/ folder

That's it. The entire replication runs in ~40 seconds and produces all
required tables + log file automatically.
