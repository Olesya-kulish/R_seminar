FINAL REPLICATION PACKAGE SUMMARY
==================================

This R replication package successfully reproduces the required tables from:
"Public Goods Under Financial Distress" by Pawel Janas

QUICK START
-----------
1. Install R packages once:
   install.packages(c("haven", "dplyr", "fixest", "tibble", "purrr", "flextable"))

2. Run the automated replication:
   source("scripts/run_all_tables_with_log.r")

This single command:
- Loads the original .dta files from the replication package
- Runs all table scripts automatically
- Writes a full execution log using sink() to output/run_log.txt
- Saves run status for each script to output/run_status.csv
