## How to Fix Issues

### Fix #1: If Table IV says to use 'check' instead of 'check_moody'

**In scripts/Table_IV_PanelA.r, change line:**
```r
# OLD:
filter(check_moody < 0.2 & check_moody > -0.2)

# TO NEW:
filter(check < 0.2 & check > -0.2)
```

Then re-run the model → Should get N=3829! ✓

---

### Fix #2: If Table III shows too many cities (681 vs 641)

**In scripts/Table_III_A.r, change:**
```r
# After this line:
df_complete <- df %>%
  filter(!is.na(post_detail)) %>%
  filter(!is.na(real_pc_maint_dep_total_log)) %>%
  filter(!is.na(pop_30), !is.na(pop_20_30)) %>%
  filter(!is.na(real_pc_rev_total_log), !is.na(L_real_pc_rev_total_log)) %>%
  filter(!is.na(leverage)) %>%
  
  # ADD THIS: Keep only balanced panels (all 17 years)
  group_by(id_) %>%
  filter(n() == 17) %>%
  ungroup()
```

Then re-run the model → Should get N=10,903! ✓

## What to Look For in Diagnostic Output

### Table IV Success Criteria:
- ✓ `check_moody` distribution shows most obs in [-0.2, 0.2] range
- ✓ Using `check` gives N=3829 (or using `check_moody` gives N=3829)
- ✓ N after year + check filter: ~3900
- ✓ N after real_pc_outlay > 0: ~3829-3850

### Table III Success Criteria:
- ✓ Unique cities: 641 (or close to it)
- ✓ Balance check shows: "✓ BALANCED PANEL"
- ✓ All years 1924-1943 (except 1939-1940) present with equal city counts
- ✓ Final N: 10,900-10,910
